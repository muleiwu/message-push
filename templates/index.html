核心特性

为生产环境打造的完备功能集

高性能架构

基于 Go 1.23+ 开发，采用 Gin 框架，内置连接池与协程池，轻松应对高并发场景。

多渠道支持

统一接口适配阿里云/腾讯云/助通 SMS、邮件、企业微信、钉钉等多种渠道，支持权重配置与智能路由。

规则引擎

内置智能规则引擎，支持失败重试、自动切换渠道、熔断降级等策略，确保消息高可靠送达。

稳定性保障

内置熔断降级、重试机制、QPS 限流与每日配额控制，保障系统稳健运行。

回调处理

支持供应商状态回调处理与 Webhook 通知，实时掌握消息投递状态。

可观测性

集成 Zap 结构化日志，提供详细的请求追踪 (TraceID) 与健康检查端点。

安全可靠

支持 AppSecret 签名验证、防重放攻击，确保 API 调用的安全性。

管理后台

提供基于 Vue.js + Ant Design 的可视化管理后台，方便进行配置管理与数据监控。

开箱即用

提供 Docker 镜像与 K8s 部署配置，支持一键初始化与数据库迁移。

技术栈

采用主流成熟的开源技术构建

  • Go 1.23+
  • Gin Web Framework
  • GORM
  • Redis
  • Viper
  • Docker
  • MySQL / PostgreSQL
  • Vue.js + Ant Design
  • Zap Logger
